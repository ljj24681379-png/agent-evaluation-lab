# 失败分类

| 类型 | 脱敏案例 | 识别信号 | 优先动作 |
|---|---|---|---|
| 模型理解 | 多产物任务漏掉 PDF；误解保留表结构的要求 | 计划与交付清单不一致 | 结构化计划、约束提取 |
| 工具调用 | 图表参数不受支持；文件生成前先调用转换 | 工具报错、schema 不通过 | 参数校验、有界重试 |
| 产物生成 | HTML 筛选未绑定；PDF 末页被截断 | 解析、渲染或交互测试失败 | 文件类型校验器 |
| 校验 / 修复 | 未校验即交付；修复没有命中根因 | 无校验记录、复检同错 | 交付门禁、结构化错误反馈 |
| 时延 | PDF 导出长时间无响应；多产物串行重复准备 | P95 显著高于平均 | 超时、复用、异步化 |
| 稳定性 | 三次中一次漏附录；偶发选择错误工具路径 | 三次全成功率偏低 | 固定回归集、减少路径分叉 |

同一次运行可以命中多个标签。分类的目的不是给模型贴标签，而是把问题指向 Prompt、工具、生成器、Agent 流程或产品架构。
