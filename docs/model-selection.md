# 模型选型：不是选“最强”，而是设计执行策略

不同模式的损失函数不同：默认模式看重稳定交付，快速模式看重等待，高质量备选需要可靠补位，复杂任务则可能需要改变产品流程。

| 模式 | 选择 | 依据 | 保护措施 |
|---|---|---|---|
| 默认 | Qwen | 成功率 94.4%，三次全成功率 83.3% | 保留最终校验 |
| 快速 | Doubao | 平均 43s，P95 76s | 限定轻量任务、允许重试 |
| 高质量备选 | DeepSeek | 成功率 90.0%，人评 A 67.8% | 超时提示、异步选项 |
| 复杂任务兜底 | 限制范围 / 异步 | Excel、多产物放大组合风险 | 分阶段状态、逐产物校验 |

复杂 Excel 应明确支持的公式、图表与工作表范围；多产物任务应复用中间结果并在全部成果通过后才标记完成。模型或工具升级后，固定复跑回归集，并同时观察成功率、三次全成功率和 P95。
